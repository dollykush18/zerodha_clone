# Zerodha Clone

A full-stack Zerodha-inspired trading platform built using React.js,
Node.js, Express.js, and MongoDB.

## 🚀 Features

- User Authentication
- Portfolio Dashboard
- Holdings Management
- Positions Tracking
- Watchlist
- Responsive UI
- Backend REST APIs
- MongoDB Database Integration

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
